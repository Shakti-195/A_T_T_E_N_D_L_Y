CSV Format Guide

Required Columns:

1️⃣

Name

Student's full name (e.g., "John Doe")

2️⃣

Student ID

Unique identifier (e.g., "STU001")

3️⃣

Email

Student's email address

4️⃣

Class Batch ID

ID of the class they belong to

Sample CSV Format:

name,student_id,email,class_batch_id
John Doe,STU001,john@example.com,1
Jane Smith,STU002,jane@example.com,1
Mike Johnson,STU003,mike@example.com,2

💡 Tips:

  • Max 1000 students per upload
  • Email must be unique
  • Student ID must be unique
  • Class Batch ID must exist
